# Fleet standard

Authored GLBs are preferred only for `sub_nautilus`, `uboat`, and `destroyer` (`prefersAuthoredGltf` in `src/render/assets.ts`). Patrol, cruiser, battleship, merchant, aircraft, and the FOB stay procedural.

The game currently mixes modern hulls with WWII weapon names (Mk-14, Mk-18, Hedgehog). That identity split is an open operator choice. This document does not resolve it and does not add meshes.

Model files and the license ledger do not establish in-game silhouette quality. Fleet visual ACCEPT stays pending.
